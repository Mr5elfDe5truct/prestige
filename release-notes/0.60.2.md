## Prestige 0.60.2 · Ollama models are back

**Fixed**
- With a Workstation whose models folder is a link to another drive (models → D:\models), Ollama 0.40 listed no models at all. Every model read as a "bad manifest" though all its files were there. That took Live (it needs Qwen3.5 2B or 4B), memory and Knowledge search (the qwen3-embedding model) and every Ollama chat model with it, and a model downloaded from the catalog finished but never showed up. Prestige now gives Ollama the folder the link leads to, and all the models are back without downloading anything again.
