## Prestige 0.62.1 · 3D splats open, and 3D tiles show the model

**Fixed**
- Clicking an Idol splat (.ply) opened the Canvas on "Loading the model…" and it never finished. The app's security settings stopped the splat viewer's decoder (a Web Worker running WebAssembly) from starting, so it waited forever. Those two are now allowed, and the splat opens. If a splat ever can't load, the Canvas now says why instead of loading forever.

**Better**
- 3D models in Renders show a picture of the model instead of a plain cube. The first time a tile comes into view, Prestige draws the model off screen and keeps the picture with the other thumbnails, so it's instant after that (and the phone's gallery gets it too).
