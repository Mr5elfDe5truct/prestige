## Prestige 0.61.0 · Faster replies with tools, a queue that survives

**New**
- **Tools load when they're needed.** Only Web search, Past chats and Your files go with every message now. The other tool groups (Workstation, Files, PowerShell, Browser control and the tool store's) are listed one line each, and the model loads a group when it needs it. A message that clearly needs one ("read notes.txt", "open PowerShell", "on Wikipedia") gets it straight away, and a loaded group stays for the rest of the chat. On Qwen3.8 27B with ten groups switched on, a one-line question went from ~13,300 prompt tokens and 19 s before the first word to ~900 tokens and 2 s.
- **The render queue survives a reload.** When the RAM fills (Swap a character can do it), Windows restarts Prestige's page and the queue used to be lost. Now the render that was going carries on (or shows as done if it finished meanwhile), and the ones that were waiting come back paused, with **resume** and **clear** under the queue.

**Fixed**
- After the page reloaded, a new render never finished in the queue: ComfyUI kept sending its progress to the old page.

**Good to know**
- A render that came back after a reload lands in Renders, not back in the chat or Film shot that asked for it.
- Under the hood, `studio.ts` and `main.ts` are split into smaller files, and every pull request now runs a typecheck, unit tests, the web build and `cargo clippy` on GitHub.
