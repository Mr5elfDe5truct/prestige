## Prestige 0.57.1 · Videos with sound work again

**Fixed**
- **LTX videos with sound start again.** Since 0.56.0, ComfyUI refused every LTX-2.5 and LTX-2.3 video with sound (from a prompt or from a picture) before it began, with *exception_during_inner_validation* on node 36. The check for Fast edits' Lightning LoRA mistook the video's sound decoder for the LoRA and removed it. It now only looks at LoRA nodes.
