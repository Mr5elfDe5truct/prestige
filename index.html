Phone access

        
Use Prestige from your phone's browser on the same Wi-Fi, or anywhere over Tailscale. It stays off unless you switch it on, only answers devices on your own network, and each phone needs the pairing code once. Chats from the phone run here and show here too. For voice chat, Live calls and the camera, install the Prestige Android app (Prestige-<version>.apk on the release page) and scan this QR code with it.

Shared memory

        
Prestige reads and writes the same memory as Open WebUI, so every model in both apps knows the same things about you.

        
To connect it: in Open WebUI open Admin Panel → Settings → General and turn on Enable API Keys, then Settings → Account → API keys → create a key and paste it here. It's saved only on this PC, in Prestige's app data folder.

Your files

      

      
Reads PDF (text, not scans), Word (.docx), text, Markdown, HTML, CSV, JSON and code. Files added from a folder or the picker are read where they are; dropped files are copied into Prestige's app data folder. Removing a file here never deletes your original.

    

    
    
      

        

          
Missions

          
Jobs Prestige runs on a schedule while it's open: a prompt for a chat model with read-only tools, or a Deep Research question. Each result is saved as a chat and Windows tells you when it's ready. Tools that would ask "Allow?" are declined, since nobody's there to answer.
