Shared memory

Prestige reads and writes the same memory as Open WebUI, so every model in both apps knows the same things about you.

To connect it: in Open WebUI open Admin Panel → Settings → General and turn on Enable API Keys, then Settings → Account → API keys → create a key and paste it here. It's saved only on this PC, in Prestige's app data folder.
